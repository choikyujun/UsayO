SECTION 03
캘린더 탭
월간 · 주간 · 일간 · 연간 4가지 뷰 — 탭 전환으로 이동
4 screens · PROMPT_09 참조
뷰핵심 요소특징인터랙션
월간 7열 그리드, 도트 인디케이터 도트 색상: 업무(보라)·개인(초록)·중요(주황) 날짜 탭 → 바텀시트 슬라이드업 (달력 유지)
주간 타임라인, 현재 시각 빨간 라인 오늘 컬럼 미세 배경 강조, 빈 시간 점선 이벤트 탭 → 상세, 좌우 스와이프로 주 이동
일간 시간 블록, 빈 슬롯 점선, 요약 칩 상단 칩: N개 일정 · N시간 여유 · 밀집도 블록 높이 = 소요 시간, 탭 → 상세
연간 12달 히트맵, 농도 5단계 가장 바쁜 달 🔥 자동 강조 달 탭 → 해당 월간 뷰 드릴다운

플로우예시 발화핵심 로직차별점
CREATE "내일 오후 3시에 팀 회의 잡아줘" 날짜 파싱 → 확인 → DB INSERT 한국어 자연어 날짜 완전 지원
UPDATE "내일 팀 회의 4시로 바꿔줘" DB 검색 → Before→After 미리보기 → UPDATE ⭐ 업계 최초 음성 수정
DELETE "내일 약속 취소해줘" 중복 시 선택 → 확인 → DELETE + 5초 되돌리기 ⭐ 업계 최초 음성 삭제
QUERY "이번 주 일정 알려줘" TTS 읽기 + 시각 리스트 동시 + 연속 대화 컨텍스트 유지 멀티턴
FAIL 소음 환경 / 낮은 신뢰도 confidence < 60% → 하이브리드 입력 전환 자연스러운 실패 복구
UPDATE 플로우 상세 — Before → After 미리보기
발화: "내일 팀 회의 4시로 바꿔줘"
① intent: UPDATE, targetQuery: "팀 회의", newTime: 16:00
② DB 검색: 내일 "팀 회의" 15:00 → 매칭 (confidence 91%)
③ 미리보기: [15:00] → [16:00] 나란히 표시
④ TTS: "팀 회의를 4시로 바꿀까요?"
⑤ 확정 (탭 또는 "응") → DB UPDATE → 완료
