## 3. 경쟁 앱 사용자 불만 분석

### Pain Point 1 — 음성 인식 정확도 문제
> *"noon에 미팅 잡아줘 → moon으로 등록됨", Todoist Ramble 베타 성공률 초기 40% → 최종 62%*

**→ 차별화**: AI 재확인 플로우 — *"3시에 회의 잡았어요, 맞나요?"* 방식으로 오인식 즉시 보정

### Pain Point 2 — 비영어권 언어 지원 취약
> *Todoist 공식 문서에도 "일부 언어는 인식이 잘 안 된다"고 명시. 한국어·일본어 정확도 격차 큼*

**→ 차별화**: 한국어/일본어/아시아어 특화 음성 최적화 — 비영어권 사실상 블루오션

### Pain Point 3 — 생성만 되고 수정·삭제 불가
> *Todoist Ramble은 입력 세션 중에만 수정 가능. 저장된 일정을 음성으로 수정·삭제하는 앱은 전무*

**→ 차별화**: 생성 + 수정 + 삭제 **완전 음성 CRUD** (Full-Cycle Voice Control)

### Pain Point 4 — 소음 환경에서 무력화
> *"배경 소음은 정확한 음성 타이핑의 적" — 이동 중, 카페 등 실제 필요한 상황에서 오히려 안 됨*

**→ 차별화**: On-Device 노이즈 필터 전처리 + 하이브리드 입력 모드

### Pain Point 5 — 음성이 보조 기능, UX 자체가 타이핑 중심
> *음성으로 시작했다가 결국 화면을 눌러야 마무리되는 불완전한 경험 반복*

**→ 차별화**: **Voice-First 설계** — 앱 실행 즉시 음성 대기, 타이핑은 보조 수단

### Pain Point 6 — 개인정보·녹음 데이터 불안감
> *사용자들의 음성 녹음 데이터 저장·활용에 대한 투명성 요구 높음*

**→ 차별화**: On-Device 처리 우선 + 명확한 프라이버시 정책 UI

## 9. 개발 전략 프롬프트

### Prompt 1 — 음성 입력 핵심 엔진 설계

```
당신은 React Native 앱에서 음성 기반 스케줄 CRUD 시스템을 설계하는 시니어 개발자입니다.

다음 요구사항에 맞는 아키텍처를 설계해주세요:
1. 사용자가 말한 내용을 STT로 변환 (Whisper API 또는 Google Speech-to-Text)
2. 변환된 텍스트를 LLM에게 전달하여 아래 4가지 인텐트로 분류:
   - CREATE: 새 일정 생성 (날짜, 시간, 제목, 반복 여부 추출)
   - UPDATE: 기존 일정 수정 (대상 일정 식별 + 변경 필드 추출)
   - DELETE: 기존 일정 삭제 (대상 일정 식별)
   - QUERY: 일정 조회 ("이번 주 일정 알려줘")
3. 인텐트 분류 결과를 JSON으로 반환
4. 결과를 TTS로 음성 피드백 ("내일 오후 3시에 팀 회의 등록했어요, 맞나요?")
5. 사용자 확인 후 실제 DB에 반영

React Native + Expo 환경 기준으로 컴포넌트 구조와 API 연동 코드 예시를 작성해주세요.
```

### Prompt 2 — 한국어 자연어 날짜/시간 파싱

```
한국어 음성 명령에서 날짜와 시간을 정확하게 파싱하는 함수를 작성해주세요.

처리해야 할 한국어 표현 예시:
- "내일 오후 3시" → tomorrow 15:00
- "다음 주 금요일 저녁" → next Friday 18:00~21:00
- "이번 달 말" → last day of current month
- "모레 아침 일찍" → day after tomorrow 08:00
- "매주 월요일 10시" → recurring every Monday 10:00
- "3일 후 점심시간" → +3 days 12:00
- "오늘 퇴근 후" → today 18:00

JavaScript/TypeScript 함수로 작성하고, 파싱 실패 시 사용자에게 재질문하는 fallback 로직도 포함.
출력 형식: { date: ISO8601, isRecurring: boolean, recurrenceRule?: string, confidence: number }
```

### Prompt 3 — 기존 일정 식별 (수정/삭제용)

```
사용자가 음성으로 "내일 회의 취소해줘"라고 말했을 때,
DB에서 해당 일정을 정확히 찾아내는 매칭 알고리즘을 설계해주세요.

조건:
- 사용자 말에 정확한 일정 제목이 없을 수 있음 ("내일 3시 거" 같이 모호하게 표현)
- 후보 일정이 여러 개일 경우 음성으로 선택지 제공
  ("내일 오후에 일정이 2개 있어요. 팀 회의인가요, 고객 미팅인가요?")
- 후보가 없을 경우 "해당 날짜에 일정이 없어요" 피드백

Supabase + React Native 환경 기준으로:
1. 퍼지 매칭 쿼리 로직
2. 후보 선택 UI/UX 플로우
3. 확인 후 삭제/수정 실행 코드를 작성해주세요.
```

### Prompt 4 — 노이즈 환경 대응 하이브리드 입력

```
소음 환경에서도 동작하는 하이브리드 음성 입력 시스템을 설계해주세요.

요구사항:
1. 음성 입력 시작 전, 마이크 입력 레벨로 소음 수준 판단
2. 소음이 높은 경우 (SNR < 15dB): 하이브리드 모드 자동 전환
   - 날짜/시간만 음성으로 말하면 나머지는 스마트 자동완성
3. 인식 신뢰도(confidence score)가 낮을 경우 자동으로 하이브리드 모드 전환

React Native + expo-av 기반 코드로 마이크 레벨 측정 + 모드 전환 로직을 작성해주세요.
```
